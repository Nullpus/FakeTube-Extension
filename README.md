# YouTube サムネ・タイトル置き換え

YouTubeで選んだ動画のサムネイルとタイトルを、好きな画像・文字に置き換えるChrome / Edge拡張機能です。
一度置き換えると、リセットするまで記憶され続けます。

> **注意**: 置き換わるのは自分のブラウザ上の表示だけです。他の人の画面やYouTube上のデータは変わりません。

## 機能

1. チャンネルページなどで、置き換えたい動画を選ぶ
2. 新しいサムネイル画像をアップロードし、新しいタイトルを入力する
3. 「置き換える」ボタンで反映する

- 置き換えは `chrome.storage.local` に保存され、ブラウザを再起動しても維持されます
- 「リセット」ボタンですべて元に戻せます(動画ごとの「解除」も可能)
- おすすめ、検索結果、関連動画、再生リスト、再生後のエンドカードなど、その動画が表示される場所すべてで置き換わります
- その動画を再生したときも、動画ページのタイトル、プレイヤーのタイトル、タブ名が置き換わります
- 「置き換え中の動画」一覧に、置き換え元の動画(サムネ・タイトル・YouTubeへのリンク)も表示されます
- 動画の選択は画面全体に透明なレイヤーを重ねて行うため、YouTube側のクリックやホバープレビューに邪魔されません
- ポップアップはライトモード/ダークモードに合わせて配色が自動で切り替わります

## インストール

まずこのリポジトリをダウンロードします(`Code` → `Download ZIP` で展開、または `git clone`)。

### かんたん導入(Windows)

1. フォルダ内の `install.bat` をダブルクリック
2. `1` (Chrome) か `2` (Edge) を入力
3. 開いた拡張機能ページで「デベロッパーモード」をオンにし、「パッケージ化されていない拡張機能を読み込む」(Edgeは「展開して読み込み」)から、開いたフォルダを選ぶ
4. 開いているYouTubeのタブを再読み込み(F5)する

※ ブラウザの仕様上、ワンクリックでの自動導入はできません。`install.bat` は拡張機能ページとフォルダを開くだけの補助です。

### Chromeに手動で導入

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダを選ぶ
4. 開いているYouTubeのタブを再読み込み(F5)する

### Edgeに手動で導入

1. Edgeで `edge://extensions` を開く
2. 左側(または左下)の「開発者モード」をオンにする
3. 「展開して読み込み」を押し、このフォルダを選ぶ
4. 開いているYouTubeのタブを再読み込み(F5)する

※ 読み込み後にフォルダを移動・削除すると拡張機能が使えなくなります。

## 使い方

1. YouTubeのチャンネルページを開き、拡張機能のアイコンから「動画を選択する」を押す
2. 置き換えたい動画をクリックする(赤枠でハイライト、`Esc`でキャンセル)
3. もう一度アイコンを開き、サムネイル画像とタイトルを入力する
4. 「置き換える」を押す
5. 元に戻したいときは「リセット」(全て)または「解除」(個別)を押す

アップロードした画像は、16:9(1280×720)に中央トリミングして保存されます。

## 注意点

- YouTubeのHTML構造が変わると動作しなくなることがあります。その場合は `content.js` 先頭の `CONTAINER_SELECTOR` を調整してください。
- 「動画を選択する」が動かないときは、YouTubeのタブを再読み込みしてください。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | 拡張機能の設定 (Manifest V3) |
| `content.js` | YouTube上での動画選択と置き換え処理 |
| `popup.html` / `popup.css` / `popup.js` | ポップアップUI |
| `icon.png` | アイコン |
| `install.bat` | 導入補助(Chrome/Edgeの拡張機能ページとフォルダを開く) |
